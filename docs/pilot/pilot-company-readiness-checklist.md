# FlowOS pilot — toelatingschecklist voor een bedrijf

## Harde regel

**REAL CUSTOMER DATA: NOT APPROVED** totdat de centrale pilotgate schriftelijk
op PASS staat. Deze checklist maakt geen bedrijf zelfstandig toegelaten.

| Controle | Pass-voorwaarde | Status |
| --- | --- | --- |
| Centrale pilotgate | CEO-go/no-go formeel vastgelegd | ☐ |
| Bedrijfsidentiteit | Juridische naam en bevoegde contactpersoon gecontroleerd | ☐ |
| Autorisatie | Contact mag namens het bedrijf deelnemen | ☐ |
| Juridische documenten | Toepasselijke voorwaarden/privacy/DPA geaccepteerd of ondertekend | ☐ |
| Contactgegevens | Support- en privacycontact gedeeld | ☐ |
| Backup/restore | Centrale BR1-gate staat PASS | ☐ |
| Tenant | Juiste productieorganisatie, geen test/smoke-tenant | ☐ |
| Entitlement | Alleen gewenste modules zijn ingeschakeld | ☐ |
| Startdata | Geen demo- of regressiondata in de nieuwe tenant | ☐ |
| Data-autorisatie | Expliciet vastgelegd dat echte data mag worden ingevoerd | ☐ |

Na toelating: deel onboardinggids, plan een eerste check-in en registreer alleen
minimale contactinformatie via het goedgekeurde kanaal.
