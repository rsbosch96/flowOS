# Product scope reminder — pilotperiode

Deze documenten scheppen geen productverplichting buiten de onderstaande
scopebeslissing.

| Status | Onderwerpen |
| --- | --- |
| **FROZEN** | Core, Planning v1, ENT1 |
| **DESIGN ONLY** | Operations/Field Service, externe kalenderintegraties |
| **POST-PILOT VALIDATION** | CRM-uitbreiding, automatisering, analytics, live AI en aanvullende add-ons |

Uitzonderingen zijn alleen securityfixes, integriteitsfixes, operationele fixes
of een expliciet CEO-goedgekeurd besluit. De pilotmaterialen beloven geen
toekomstige module, datum, prijs, SLA of integratie.
